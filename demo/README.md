Duration: **1:55.04**. H.264 video, 1920×1080, 25 fps, English AAC narration and burned-in English captions. If your browser downloads the MP4 instead of playing it, open the downloaded file in a video player.

The demo records real operations on the public website while signed out: recipe-link review, supported English/Chinese ingredient names, alternative selection, a combined grocery list, serving adjustments, editing, pantry checks, image/text export and persistence after refresh.

Recipe inputs were transcribed before recording. The video does not demonstrate live ChatGPT image inference, cloud sign-in or cloud synchronization. Signed-out state is saved in the current browser. Some names and notes retain their source language. Firecrawl and AgentMail are not demonstrated integrations.

The user supplied the edited video. Its production notes attribute narration to local Kokoro with the af_heart voice; the website itself does not use Kokoro. Full audio/video decoding and the subtitle text were checked before publication. No background music was added.
